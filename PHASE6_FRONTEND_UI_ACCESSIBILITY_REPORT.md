# Phase 6 — Frontend, UI/UX & accessibility upgrade

## Scope

This phase adds interaction-state, responsive, semantic, visual-regression, and assistive-technology evidence to representative Group 05 skills. Existing mature references remain authoritative and are not duplicated.

## New focused packs

| Skill | New material |
|---|---|
| `sk-frontend-design-pro` | Responsive visual evidence across viewport, content, theme, preference, and localization variants |
| `sk-mobile-design-pro` | Touch targets, safe areas, navigation, keyboard, permissions, offline, dynamic type, RTL and device classes |
| `sk-a11y-design-pro` | Semantics, keyboard, screen reader, contrast, zoom/reflow, forms, widgets, preferences and audit evidence |
| `sk-design-system-pro` | Component states, token/theme blast radius, content resilience, visual and semantic gates |
| `sk-react-pro` | Async state, forms, overlays, races, Strict Mode, hydration, lists, responsive and a11y behavior |
| `sk-accessibility-compliance` | Severity-based audit, manual AT testing, remediation ownership and regression evidence |

## Acceptance evidence

Each pack is linked from its owning skill and defines realistic interaction states, failure boundaries, expected visual/semantic evidence, and handoff to implementation or testing owners.
