# Phase 9 — Git, tooling, platform and meta-skills upgrade

## Scope

This phase adds operational evidence to representative Group 10 skills: safe Git changes, worktree isolation, repository-tool artifact lifecycles, routing precedence, protected-command gates, capability-based tool discovery, authoring review gates and meta-review triage.

## New focused packs

| Skill | New material |
|---|---|
| `sk-git-operations-pro` | Safe change, review, recovery and publish gates |
| `sk-git-worktree-pro` | Isolation lifecycle and dirty-workspace safety |
| `sk-repo-tooling-pro` | Capability-to-command mapping and artifact lifecycle |
| `sk-router-pro` | Routing precedence, ambiguity resolution and high-impact gates |
| `sk-gatekeeper` | Structured allow/block/defer evidence record |
| `sk-tool-discovery` | Capability routing and safe fallbacks |
| `sk-skill-authoring` | Ownership, routing, contract, resource, validation and publish gates |
| `sk-skills-self-review-pro` | Deterministic vs heuristic findings, staleness, duplicates and automation limits |

## Acceptance evidence

Each pack is linked from its owning skill and preserves the repository's least-disruptive safety posture. The packs require real state, artifact IDs, command/output evidence and explicit limitations; they do not authorize destructive actions or replace domain review.
