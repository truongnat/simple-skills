# Algorithm — integration map

| Skill | Combine when |
|-------|----------------|
| **`sk-testing-pro`** | Property-based tests, adversarial inputs, regression suite for known bugs. |
| **`sk-data-analysis-pro`** | Plotting runtimes, distribution of inputs, A/B of implementations. |
| **`sk-typescript-pro` / `sk-javascript-pro`** | Language-specific numeric limits, BigInt, typed arrays. |
| **`sk-postgresql-pro`** | When “algorithm” is actually query + index design — delegate SQL side. |
| **`sk-network-infra-pro`**, **`sk-deployment-pro`**, **`sk-caching-pro`** | Distributed execution, reliability, memoization at system boundary — pair with **`algorithms-in-systems.md`** |

**Boundary:** **`sk-algorithm-pro`** owns modeling, strategy, correctness/complexity, and algorithmic patterns; **system integration** (queues, shards, SLAs) is shared with stack skills.
