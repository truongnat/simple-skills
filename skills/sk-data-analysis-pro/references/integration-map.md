# Data analysis — integration map

| Skill | When |
|-------|------|
| **`sk-sql-data-access-pro`** | Parameterized SQLite extracts; SQL hygiene before pandas |
| **`sk-postgresql-pro`** | Pushdown aggregates, indexing, warehouse-scale patterns |
| **`sk-content-analysis-pro`** | Qualitative coding of free text — not pivot tables alone |
| **`business-analysis-pro`** | KPI definitions, roadmap narrative from metrics |
| **`sk-market-research-pro`** | External sizing assumptions validation |
| **`sk-security-pro`** | Anonymization, safe exports, notebook redaction |
| **`sk-testing-pro`** | Golden checks for analytical pipelines / regression tests on transforms |
| **`sk-algorithm-pro`** | Heavy algorithmic complexity or complexity proofs — rare for standard EDA |
| **`sk-repo-tooling-pro`** | Batch scripts, repeatable pipeline wiring |

**Boundary:** **`sk-data-analysis-pro`** owns **tabular computation, visualization discipline, spreadsheet delivery**; **`sk-postgresql-pro`** owns **live database** design/ops beyond ad-hoc extracts.
