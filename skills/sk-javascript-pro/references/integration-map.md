# JavaScript — integration map

| Skill | Combine when |
|-------|----------------|
| **`sk-typescript-pro`** | Types, `strict` config, generics, narrowing — not hand-wavy `any`. |
| **`sk-testing-pro`** | Regression tests for async ordering, timers, mocks, ESM/CJS test runner setup. |
| **`sk-security-pro`** | `eval`, dynamic `Function`, prototype pollution, unsafe deserialization. |
| **`nodejs`-adjacent** | **`sk-nestjs-pro`**, **`sk-nextjs-pro`** for framework-specific server/runtime patterns. |
| **`sk-react-pro`** | Client bundles, hydration, browser-only APIs — not generic JS service code. |
| **`sk-code-packaging-pro`** | `package.json` `exports`, dual ESM/CJS publishing. |

**Boundary:** **`sk-javascript-pro`** owns language/runtime semantics; framework skills own conventions and lifecycle.
