# Self-improve agent — integration map

| Skill | When |
|-------|------|
| **`sk-feedback-pro`** | Structured review signals, severity, evidence quality. |
| **`planning-pro`** | Phased improvement waves, milestones, capacity. |
| **`sk-testing-pro`** | Regression suites, scenario tests, eval harness in CI. |
| **`sk-repo-tooling-pro`** | Batch metrics, `analyze-skills`, repo audit automation. |
| **`sk-skills-self-review-pro`** | Meta-quality for bundled skills and authoring rules. |
| **`sk-git-operations-pro`** | Branch/PR hygiene for harvested skill contributions. |
| **`sk-security-pro`** | Human gate and threat review when agents touch sensitive data or tooling. |
| **`sk-bug-discovery-pro`** | Systematic repro when failures are intermittent or environmental. |

**Handoff:** **`sk-self-improve-agent-pro`** owns the **improvement loop design**; paired skills supply **signals**, **plans**, **tests**, and **shipping** discipline.
