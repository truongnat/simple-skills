# Skill authoring review gates

| Gate | Required evidence |
|---|---|
| Ownership | Name, boundary, adjacent skills and handoffs are explicit |
| Routing | Description has concrete triggers, exclusions and compatible tools |
| Contract | Inputs, outputs, safety limits and required artifacts are testable |
| Depth | Worked scenario, failure modes, verification evidence and next owner exist where applicable |
| Structure | Six-layer order is intact; `SKILL.md` stays navigable and deep content is referenced |
| Resources | Every bundled path exists; templates are labeled; examples do not masquerade as mandatory files |
| Validation | Catalog validator, Markdown fence/link scan and relevant tests pass |
| Publish | Manifest/target scope reviewed; unrelated files and user artifacts excluded |

A skill is not ready because its prose sounds plausible. Record the exact checks, files, skipped checks and remaining limitations.
