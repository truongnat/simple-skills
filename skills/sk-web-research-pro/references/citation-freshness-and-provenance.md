# Citation freshness and provenance matrix

| Claim type | Preferred source | Required provenance |
|---|---|---|
| API behavior | Official versioned docs, changelog, primary repo | Product/version, URL/path, section, access date |
| Security behavior | Vendor advisory, standard, primary disclosure | Affected versions, publication date, severity/context |
| Pricing/limits | Official pricing/terms page | Region/currency, effective date, plan/version |
| Project-specific fact | Local source of truth/KB | File path, heading/line or artifact ID, snapshot |
| Industry/market claim | Primary filing/official data or named reputable report | Geography, period, methodology, access date |

For each material claim, label fact/inference/opinion, record source quality, and flag stale or conflicting evidence. Re-run time-sensitive citations at delivery time; do not imply that a link alone proves the claim.
